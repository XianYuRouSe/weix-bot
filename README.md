# 微信回复机器人（Weix Bot）

一个跑在你自己电脑上的微信自动回复工具：读本机微信 4.x 的聊天数据库，按每个人单独的
「关系 / 语气 / 习惯」画像生成回复，再通过界面自动化把话说出去。

**只用标准库 + Windows 自带能力**：不需要 `pip install`，不需要第三方微信客户端，
不需要注入 DLL。

> **请先读这一段**
>
> * 本项目只适用于**你自己的账号、你自己的电脑**。把它装在别人的电脑上读别人的聊天记录，
>   在很多国家和地区是违法的。
> * 自动操作微信界面属于微信不鼓励的行为，**有被风控、限制登录甚至封号的风险**，后果自负。
> * 识别的聊天内容会被发送给模型服务商（默认 DeepSeek）用于生成回复，请自行判断是否接受。
> * 本项目与腾讯无关，未获其授权。

## 它能做什么

- 只对**白名单里的人**自动回复，其他会话一概不碰；
- 按人设分人：每个联系人一份画像（关系、语气、回复长度、说话习惯、禁忌）；
- 会看作息：上班 / 通勤 / 在家 / 休息 / 睡觉，不同时段说法不一样；
- 消息合并（默认 8 秒），同一个人连发几条只回一次；
- 回复前做两道校验：数据库里确认名字唯一对应一个 wxid、再用 OCR 核对聊天窗口标题；
- 关系会随时间变化：每天分析一次新增聊天，关系变了先提示，超时未确认再自动应用；
- 图片会截图给视觉模型看，语音会调用微信「转文字」再读出来。

## 环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（x64） |
| 微信 | 4.x，且已登录 |
| Python | 3.9 及以上（只有源码运行时需要） |
| OCR | 系统自带中文 OCR 语言包（中文系统一般已装） |
| 模型 | 一个 DeepSeek API key（自费） |

## 快速开始

1. 下载并解压到任意目录（路径里有中文、空格都没关系）；
2. 双击 **`首次配置.bat`**，按提示走：
   - 选择微信数据目录（会自动搜索，也可以手动粘贴路径）
   - 输入 master key（怎么拿见 [docs/取密钥说明.md](docs/取密钥说明.md)）
   - 填 API key
   - 选要自动回复的人
   - 跑只读自检（能解库、能读消息、能认出微信窗口）
3. **写你自己的人设**：打开控制面板 →「参数 → 全局人设」，把模板里括号中的例子
   换成你自己的说话方式（身份、长度、标点、口头禅、不聊的话题）。
   这一项没有通用答案，只能你自己写；不写也能跑，但回复会很空、很像客服。
4. 双击 **`启动机器人.bat`**，再双击 **`打开控制面板.bat`** 看状态。

> **第一次运行默认是「安全模式」**：只生成回复并写日志，不往微信里发。
> 确认生成的内容没问题后，在控制面板「参数」页勾上「允许真实发送」，或者把
> `config/bot.json` 里的 `send_enabled` 改成 `true`。

## 配置说明（`config/bot.json`）

| 键 | 说明 |
|---|---|
| `whitelist` | `{wxid: 名字}`，只有这里的人会被自动回复 |
| `persona` | 全局人设，分 Layer 0–4，硬规则写这里 |
| `model` / `vision_model` | 对话模型 / 图片模型 |
| `debounce_seconds` | 合并等待秒数 |
| `min_reply_interval` | 同一会话最小回复间隔 |
| `max_message_age_seconds` | 超过这个时间的消息不回 |
| `send_enabled` | `false` = 安全模式，只生成不发送 |
| `schedule` | 上下班、睡眠、节假日、调休 |
| `evolution` | 关系演化：`enabled` / `daily_seconds` / `pending_hours` / `cooldown_days` / `min_new_messages` / `confidence_min` |

每个人的画像在 `config/profiles.json`，可以在面板里改，也可以让它每天自动更新。

## 数据与隐私

- 微信数据库在**本机**解密，明文缓存在 `cache/`，退出后可以随时删；
- 只把**要回复的那一段对话**发给模型，不上传全量记录；
- `logs/` 里会记录消息片段和生成的回复，自己注意保管；
- 密钥保存在 `config/all_keys.json`，**它等价于你的全部聊天记录**，不要外传、不要提交到仓库。

## 已知限制

- 界面自动化依赖微信窗口布局：换分辨率、改缩放、微信大改版都可能让它点偏。发送前的
  “名字唯一性 + OCR 标题校验”是为了兜住这件事，请别关掉；
- 同一时间只支持一个微信账号；
- 语音转文字依赖微信自带的「转文字」菜单项，菜单改了就会跳过语音；
- 关系判断是模型给的，会误判，所以设计成“先提示、再应用”，不要关掉提示。

## 开发

```bash
# 语法检查
python -m compileall app

# 只跑自检，不改配置
python app/setup.py --check-only
```

没有第三方依赖，不需要虚拟环境。改完代码重启机器人生效。
